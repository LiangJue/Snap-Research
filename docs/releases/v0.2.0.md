# Snap Research v0.2.0

Private release candidate for final review.

## Install

1. Download `snap-research-v0.2.0-chrome.zip`.
2. Extract it to a permanent folder.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Choose **Load unpacked** and select the extracted folder containing
   `manifest.json`.

See [the detailed installation guide](../INSTALL.md) for first use, updates,
backup advice, and troubleshooting.

## Highlights

- send a raw screenshot to the user's existing ChatGPT session without a
  Research API key;
- write the structured research prompt into the ChatGPT composer without
  automatically sending it;
- stop controlling the composer immediately after insertion so ChatGPT owns
  submission and clearing;
- split and investigate up to ten screenshot claims in one structured response;
- validate and import each claim as an independent Evidence Card;
- normalize Markdown-formatted source URLs and common tracking parameters;
- preserve usable qualitative evidence when optional numeric metadata is
  incomplete;
- replace the Report's waiting placeholder with the imported claim checklist
  and completed status.

## Verification
