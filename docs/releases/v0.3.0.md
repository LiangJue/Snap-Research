# Snap Research v0.3.0

Private test release adding Kimi and selected-text web research.

## Install

1. Download `snap-research-v0.3.0-chrome.zip`.
2. Extract it to a permanent folder.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Choose **Load unpacked** and select the extracted folder containing
   `manifest.json`.

See [the detailed installation guide](../INSTALL.md) for updates, backup advice,
and troubleshooting.

## Highlights

- send a raw screenshot to ChatGPT or Kimi without the local Research API;
- send selected webpage text directly to ChatGPT or Kimi before claim extraction;
- optionally extract and edit claims first, then choose API, ChatGPT, or Kimi research;
- write the source material and structured prompt into the chosen web composer
  without automatically sending it;
- import structured Kimi results into the original Research Report and Evidence Cards;
- preview imported tasks and evidence before confirmation;
- optionally keep or omit the complete source AI conversation;
- stop controlling the Kimi composer after the first write, including when Kimi
  temporarily renders only part of a long prompt.

## Kimi composer fix

Kimi reconciles long rich-text prompts asynchronously. Earlier retries could
misread a partial render as failure, rewrite the composer every 250 milliseconds,
and restore the prompt after submission. The v0.3.0 bridge claims page-level
ownership before the first mutation, performs one input transaction, and treats
later retries as acknowledgements rather than new writes.
