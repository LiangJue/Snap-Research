Private Chrome-profile testing release.

- reorganized popup header actions and added a direct Library shortcut;
- promoted **Capture & Research** to a dedicated primary row;
- added distinct selected-text research entry-point copy and regression tests;

- TypeScript compilation and ESLint passed;
- 37 focused release test files / 153 tests passed;
- Chrome MV3 production build and Chrome-safe encoding check passed;
- the Library entry, region capture, selected-text context menu, and Fetch AI
  Chat passed manual smoke testing.
