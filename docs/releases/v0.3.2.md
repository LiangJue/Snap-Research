# Snap Research v0.3.2

Private bug-fix release for reliable ChatGPT and Kimi Research imports.

## Install

1. Download `snap-research-v0.3.2-chrome.zip`.
2. Extract it to a permanent folder.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Choose **Load unpacked** and select the extracted folder containing
   `manifest.json`.

When updating an existing unpacked installation, replace the files in the same
folder and click **Reload**. Keeping the same folder preserves the extension
identity and its browser-local Research Reports.

## Fixes

- an inconsistent derived `changeRate` no longer aborts an entire manual
  ChatGPT or Kimi import;
- the importer removes only the invalid derived rate, keeps the underlying
  values and evidence, and records the adjustment in the card limitations;
- internal import errors are converted into actionable messages;
- import errors are shown inside the still-open confirmation dialog instead of
  being hidden behind it;
- local `docs/research/` source material is explicitly ignored by Git;
- inherited store-publishing and release workflows no longer run automatically
  when a Snap Research tag is pushed.

## Verification

- 38 focused release test files / 156 tests passed;
- TypeScript compilation and ESLint passed;
- Chrome MV3 production build and Chrome-safe encoding check passed;
- screenshot-first ChatGPT research completed prompt delivery, web research,
  preview, confirmed import, and Report generation in a real Chrome profile;
- selected-text ChatGPT research completed the same end-to-end import flow;
- the updated build was copied over the existing unpacked installation and
  successfully imported into the original browser-local Research Report.

## Known limitations

- the optional local Research API remains a prototype without production
  authentication;
- ChatGPT and Kimi imports validate the returned structure but cannot
  independently prove that every reported source was visited;
- Research Quality Gate improvements remain planned for a later release.

## Privacy and license

The packaged build contains no API key or local Research Report. ChatGPT and Kimi
web paths do not read account credentials or cookies and do not automatically
send messages. See [PRIVACY.md](../../PRIVACY.md).
