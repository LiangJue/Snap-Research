# Snap Research v0.3.4

First audited public release of Snap Research.

## Install

1. Download `snap-research-v0.3.4-chrome.zip`.
2. Extract it into an empty permanent folder.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Choose **Load unpacked** and select the folder containing `manifest.json`.

## Public-readiness fixes

- removes message previews, conversation identifiers, complete image URLs,
  exception messages, and tab-creation stack traces from diagnostic logs;
- makes tab-creation diagnostics opt-in and limits the recorded URL to its
  origin;
- recursively removes nested API keys, tokens, secrets, passwords, and
  authorization values from exported backups;
- removes inherited Obsidian screenshots that could expose a credential or
  encourage sharing one;
- removes inactive inherited store-publishing and unsupported alternate-browser
  packaging infrastructure;
- corrects the damaged Chinese accessibility label and stale Public wording.

## Release policy

- Snap Research publishes a Chrome MV3 ZIP through GitHub Releases.
- Earlier private test packages are superseded and are not supported for new
  installations.
- The repository retains SyncNos attribution and the GNU AGPL-3.0 license.
