# Snap Research v0.3.3

Private public-readiness candidate for Snap Research. Public release remains
pending completion of the repository audit and a separate explicit approval.

## Install

1. Download `snap-research-v0.3.3-chrome.zip`.
2. Extract it into an empty permanent folder.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Choose **Load unpacked** and select the folder containing `manifest.json`.

Before updating an existing unpacked installation, export a backup. Clear the
old packaged files from its permanent folder before extracting v0.3.3 into that
same folder, then click **Reload**.

## Research Quality Gate

- preserves direct support/counter evidence when the same source URL also
  appears as context;
- conservatively re-estimates invalid evidence tiers and downgrades
  source-inconsistent A1/A2/B claims;
- reduces unsupported statuses to `insufficient` and visibly marks the original
  conclusion for review;
- flags suspicious compound `mixed` claims that should be split;
- removes inconsistent derived change rates without discarding the underlying
  evidence;
- separates system checks from source limitations;
- shows original source material and the manual-import disclosure once at the
  Report level instead of repeating them in every card;
- adds a Report-level status summary.

The gate is deterministic. It cannot independently read every cited page or
guarantee complete claim coverage, so users must still open important sources
and make the final judgment.

## Security and privacy

- updated Defuddle, MathML/XML, Markdown, linkification, and React Router
  dependencies;
- the full dependency graph is checked by `npm run audit:deps`;
- the remaining npm advisory concerns React Router Server/RSC Action handling;
  the static MV3 extension uses only the audited client-side HashRouter APIs;
- the build contains no source map, API key, local path, or Research Report;
- `docs/research/` is ignored and has never been tracked in this repository.

See [the v0.3.3 security audit](../security-audit-v0.3.3.md) and
[PRIVACY.md](../../PRIVACY.md).
